# Ball-on-Plate Robot Simulation in MATLAB

Research-grade MATLAB simulation of a self-balancing ball-on-plate robot using four stepper-driven linkage legs.

## Features

- Nonlinear rolling ball dynamics
- Cascaded path-following control
- LQR-style tracking controller
- Four-leg linkage inverse kinematics
- Stepper actuator dynamics
- Advanced reference trajectory generation
- 3D visualization and diagnostic plots

## Requirements

- MATLAB R2020b or newer recommended
- Core MATLAB graphics

## Run

Open MATLAB in this folder and run:

```matlab
Ball_On_Plate_Research_Grade_Simulation
```
